## 2. Mobile Navigation Architecture & Screen Inventory

### Role-Aware Bottom Navigation Shells

#### 1. Guest / Customer Shell (5 Tabs)
1. **Beranda (`HomeScreen`)**: Hero search trigger, city quick filters, popular/newest kos, quick actions.
2. **Eksplor (`ExploreScreen`)**: Live search bar, horizontal filter pills (type, city, price, facilities sheet, sort), paginated kos list/cards.
3. **Favorit (`FavoritesScreen`)**: Saved kos wishlist (prompts login if guest).
4. **Aktivitas (`MyActivityScreen`)**: Segmented tabs for **Booking**, **Invoice**, **Survei**, and **Laporan Kerusakan** (replaces bulky desktop sidebar).
5. **Profil (`ProfileScreen`)**: User card, Edit Profile, Pesan/Chat shortcut (or Chat badge in top bar), Notifikasi, Bantuan & Tentang, Logout.

*(Note: Direct Chat & Notifications icons with unread badges live in the persistent AppBar of Home/Activity so users reach messages in 1 tap.)*

#### 2. Property Owner Shell (5 Tabs)
1. **Dashboard (`OwnerDashboardScreen`)**: KPI grid, quick actions (Tambah Kos, Pending Approvals, Surveys, Maintenance), recent properties.
2. **Properti (`OwnerKosListScreen`)**: Manage kos list, FAB to create kos, quick access to Room Inventory & Edit.
3. **Booking (`OwnerBookingsScreen`)**: Tabbed filter (`Pending`, `Approved`, `Confirmed`, `Active`, `Completed`, `Rejected`) + quick link to Active Tenants (`Penghuni`).
4. **Pesan (`ChatListScreen`)**: Conversations with prospective and active tenants.
5. **Lainnya (`OwnerMoreScreen`)**: Survei Masuk, Laporan Kerusakan, Penilaian & Ulasan, Statistik & Pendapatan, Notifikasi, Profil Pemilik, Logout.
